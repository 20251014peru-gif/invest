각 채널의 요약 프로필입니다. 수정 지시를 한 줄 적으면 AI가 프로필을 다시 씁니다. 🔍 관통 분석은 요약 2편 이상 쌓인 채널에서 반복되는 판단 방식·프레이밍 패턴을 분석합니다.
채널이 영상에서 어떤 조건을 보고 어떻게 해석해서 어떤 결론·행동으로 이어지는지, 요약이 쌓일 때마다 자동으로 정리됩니다. 맞았는지 틀렸는지는 채점하지 않습니다 — 판단 방식 자체를 배우기 위한 노트예요. 영상을 어떤 순서로 요약하든 항상 게시일 기준(과거→현재)으로 다시 정리됩니다.
채널을 선택하면 판단노트가 표시됩니다.
웹 검색으로 실시간 시장·섹터를 점검합니다. 종합 버튼은 여러 항목을 조사해 하나로 판단(느리고 크레딧↑), 개별 버튼은 한 항목만(빠름).
🌍 1단계 · 매크로 (시장 전체)
🏭 2단계 · 섹터 (반도체·AI 등)
📊 3단계 · 종목
개별 종목은 요약 탭의 종목 빠른 확인 + 삼각형 판정을 쓰세요. (매크로→섹터→종목 순으로 좁혀가면 탑다운 완성)
저장된 모든 요약에서 답을 찾습니다. 예: "SK하이닉스 ADR 언급한 채널?", "반도체 조정을 경고한 사람은?"
모든 채널을 유도비율(프레이밍)이 낮은 순으로 정렬합니다. 정보형인지 흥미 유도형인지 한눈에.
