# 아침보고서 거래일·마감 원칙

판본: 2026-10-01.1. 기존 매시 05분 GitHub Actions 수집을 재사용한다.

정규판 기준은 08:20 KST. 작업 시작시각이 아니라 **응답 확보와 묶음 저장 완료시각**이 마감 이내여야 한다. 마감 전 마지막 완료 묶음을 후보로 저장하고, 마감 후 첫 정상 실행에서 날짜별 정규판으로 고정한다. GitHub 예약은 실행 지연 가능성이 있으므로 08:20 정시 발행을 보장하지 않는다. 자료 기준시각과 실제 생성시각을 함께 표시한다.

- 후보: `facts/report_candidates/YYYY-MM-DD.json`
- 정규판: `facts/report_editions/YYYY-MM-DD/snapshot.json` (생성 후 자동 덮어쓰기 금지, SHA-256 확인)
- 현재판: `facts/market_report_feeds.json`
- 실행 상태: `facts/market_report_clock.json`
- 달력과 개별 계열 규칙: `data/report_clock_policy.json`

10월 1일 기존 08:17 보고서는 보존한다. 이번 배포 후 얻은 자료로 당시 정규판을 재구성하지 않는다. 마감 전 자료가 없으면 `no_pre_cutoff_snapshot`을 기록한다. 후보 파일의 관측일·값·수집시각을 그대로 사용하며 사후 정정은 다음 판에만 반영한다.

미국 주식은 NYSE/Nasdaq 정규장과 조기 마감, 한국 주식은 공휴일·근로자의 날·연말 휴장 규칙을 적용한다. SOFR은 SIFMA 전면 휴장, EFFR은 뉴욕연준 휴일을 각각 사용한다. SOFR 예상 발표는 08:00 ET, EFFR은 09:00 ET이며 직전 해당 영업일 거래를 가리킨다. ET는 미국 일광절약시간을 적용한다. 예정 공표시각을 실제 공표시각으로 저장하지 않는다.

예정 달력은 2026년 범위이며 11월 1일 재점검 기한이 도래하면 자동으로 미검증 상태가 된다. 임시 휴장은 기관 공지 확인 후 버전을 갱신해야 한다. 검증되지 않은 관측·공표 달력은 임의 평일 규칙으로 대체하지 않는다. 특히 신용 OAS·ECOS 금리/환율·Treasury 재배포의 세부 달력은 현재 참고 상태이며, 연결 성공과 구분한다.

상태: 달력 기준 최신 / 최신이지만 비교일 누락 / 최신 거래일 미수신·공표시각 미확인 / 예상 발표시각 경과 / 달력 미확정 / 마감 후 확보 / 수집 오류. 누락을 0이나 전일 복제값으로 채우지 않는다. 최신값이라도 직전 완료 거래일이 빠지면 대시보드 변화율은 비우고 상세에 관측값 간 변화만 남긴다.

`data_eligible`은 기준시각과 관측일 검사 통과일 뿐, 매매 적격이 아니다. 독립 출처 교차 검증과 인과관계 확인도 별개다. `signal_eligible`은 계속 false다.

공식 근거 URL은 달력 JSON에 보존한다. 복구는 이 판의 코드만 되돌리고 기존 후보·정규판 파일은 삭제하지 않는다. 원응답은 기존 Actions artifact 30일, 정규화 묶음은 Git 이력으로 보존한다. 개인 장부·매매규칙을 공개 저장소에 추가하지 않는다.
