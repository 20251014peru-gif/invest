# 시장 톱니바퀴 아침보고서 제작 지침서 v2.0 (우리 프로그램용)

기준: GPT "실전 아침보고서 제작 지침서 v1.0"의 디자인·페이지 구조를 이어받고, 약점을 고쳤다. 판단(매수·매도, 임계값)은 달님 몫이며 이 문서와 보고서는 판단 재료만 만든다.
구현: `tools/report/` (lib.py 그림·PDF 도구, content_<날짜>.py 그날 내용, build.py 실행). 이슈 장부: `analysis/issue_ledger.json`. 명세: `docs/MACRO_DAILY_REPORT_SPEC.md`.

## 1. 그대로 살린 것 (GPT v1.0의 장점)
- A4 8~12쪽, 남색 헤더, 색 의미 고정(빨강=위험, 주황=주의, 파랑=확인, 청록=완화)
- 쪽 순서: 요약 → 변화표 → 차트 → 세계→한국 전달 → 이슈 장부 → 유가·금리 → AI·반도체 → 신용·강제매도 → 한국·행동규칙 → 출처·한계
- 이슈 수명주기, 위험 1~4단계, 방향 불일치 표시, 사실과 가설의 분리, "발언≠행동≠주문≠실적" 판단 트리

## 2. 고친 것 (약점 → 수정)
| GPT v1.0의 약점 | v2.0 수정 |
|---|---|
| 신뢰도 A/B/C가 출처 등급과 가설 등급을 한 축에 섞음 | 출처 등급 ◎○○*△✕ 와 `가설` 태그 두 축으로 분리 |
| 임계값(5.30%, −2~−3%, −15%)을 지침서가 정함 | 달님 확정 전에는 "예시"로만 표시하고 규칙 충족 판정은 미확인 처리 |
| 수집 안 한 지표가 조용히 빠지고 안정처럼 읽힘 | 위험단계에 "판정 가능 축 n/3" 표기, 데이터 공백 패널 필수 |
| 소멸 판정이 중심 | 흐름 → 반대급부 → 자금 이동으로 재구성. 소멸은 세 조건 동시 확인 때만 |
| 전일 상태를 어디서 잇는지 없음 | `analysis/issue_ledger.json`에 ID·단계·최초 근거일·반대/반증 조건 저장, 다음 날 이어받음 |
| 이슈별 한국 영향이 약함 | 4쪽 세계→한국 전달과 9쪽 유불리 톱니, 이음매마다 검증자료 명시 |
| 출처 원문 대조 가능 여부를 밝히지 않음 | 10쪽에 "원문 미열람" 한계를 맨 위에 고정 |
| 시점 혼합(장중·종가·선물) | 07:00 KST 기준 고정, 이후 발표분은 "07시 이후" 별도 표기 |
| 예측이 반증되지 않음 | 각 이슈에 반증 조건과 다음 검증 시점 기록, 빗나간 예측은 정정 이력에 남김 |

## 2-B. 접근 상태 축 (GPT 지침서 3.4~3.5에서 채택)
출처의 권위(A 공식/B 통신사·복수매체)와 원문을 실제로 열었는지를 따로 적는다.
- D 원문·공식 표 직접 확인 / R 합법 재게시본 확인 / S 검색요약만 / F 사용자 제공 파일 / U 접근 실패
- S만 있는 숫자는 결론표에서 빼고 "잠정·원문 미확인" 칸에 둔다. 핵심 결론의 단독 근거로 쓰지 않는다.
- 핵심 숫자 대부분이 S이면 보고서를 완성판이라 하지 않고 **제한판**으로 표기한다. (2026-09-30 v1.0은 제한판)
- 표기 예: `B/S`(통신사 기사를 검색요약으로만 봄), `A/D`(공식 표를 직접 열어 확인)

## 3. 검증 4단 방어선 (인터넷 검증 한계 대응)
1. 숫자는 코드가 수집한 값(`facts/`)을 우선한다. 손으로 옮긴 숫자는 검색 요약 등급(○) 이하.
2. 주장 장부: 문장마다 등급(◎○○*△✕)을 붙인다. 충돌(△)은 결론에서 뺀다.
3. 교차 공격: 완성본을 다른 AI(GPT)에 넘겨 반박시키고, 반박은 원자료로 재대조한다.
4. 예측 장부: 반증 가능한 예측만 쓰고 결과를 다음 보고서에 채점한다.
0을 보장하지 못한다. 달님의 감시는 영구 부품이다.

## 4. 매일 실행 순서
1. 지표 수집 (`facts/macro.json`, `facts/macro_history.json` 갱신, 공백은 공백으로 둔다)
2. `analysis/issue_ledger.json` 이어받기: 단계·최근 확인일 갱신, 새 이슈는 새 ID
3. 전일 대비 방향 불일치 3개 선정 → 가설로 표시하고 검증자료 지정
4. `tools/report/content_<날짜>.py` 를 전일 파일에서 복사해 값과 문장 교체 (구조만 이어받는다)
5. 빌드: `NSK_FONT_DIR=<Noto Sans KR 폴더> python3 tools/report/build.py <날짜> --preview`
6. 쪽별 PNG로 넘침·부호·쪽번호·단위 확인, 10쪽 유지
7. GPT 교차 공격 → 정정 → 확정본 → 달님 검토
