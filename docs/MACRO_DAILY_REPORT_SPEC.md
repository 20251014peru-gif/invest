# 아침 매크로 보고서 규격 v0.1 (초안)

작성 2026-09-30. 상태: **설계 초안 — 프로그램 변경 없음.** 먼저 사람이 이 틀로 보고서를 받아보고, 유용하면 그다음에 저장·자동화를 붙인다.

## 0. 목적과 경계

- 목적: 미국·세계 시장의 변화를 아침에 한 장으로 받아, 한국 자본시장 투자 판단의 **재료**로 쓴다.
- 보고서는 "무엇이 바뀌었나 / 왜 중요한가 / 무엇이 확인·반증되었나"까지만 쓴다. **사자·팔자는 쓰지 않는다** (판단은 달님).
- 실시간 감시가 아니다. 하루 1회(+장중 전제가 뒤집힌 경우 수시) 갱신하는 판단 장부다.

## 1. 확인 등급 (모든 문장·숫자에 붙인다)

| 표기 | 뜻 | 허용 조건 |
|---|---|---|
| `[확인]` | 출처와 기준시각이 있는 값·사실 | 링크 또는 `facts/…` 파일·항목 ID |
| `[추정]` | 작성자(AI 포함)의 해석·인과 | 근거가 된 `[확인]` 항목을 같이 적음 |
| `[미확인]` | 들었지만 출처를 못 댐 | 판단 근거로 쓰지 않음, 부록에만 남김 |
| `[의견:인물]` | 유튜버·연준 인사 등 타인의 주장 | 주장자·날짜·원문 링크. 사실로 승격 금지 |

규칙
1. **숫자는 코드가 채운다.** 표의 값은 `facts/macro.json` 등 수집 파일에서만 가져오고, AI가 서술 중에 새 숫자를 만들지 않는다. 표에 없는 숫자를 쓰려면 `[확인]`+원문 링크가 있어야 한다.
2. **뉴스는 원문 링크 없으면 `[미확인]`.** 기사 제목만으로 사실 확정 금지.
3. 값에는 항상 `기준일(as_of)`과 `수집시각`을 함께 쓴다 (`MACRO_STANDARD.md` §9).
4. 임계값(예: "10년물 5.25%")은 **[의견:인물]** 로 표기한다. 우리 기준으로 승격하려면 과거 분포로 검증한 뒤에만.

## 2. 보고서 본문 구조 (휴대폰 3~5분 분량)

### A. 헤더
- 기준 시각, 데이터 신선도 요약(오래된 지표 목록), **어제 보고서와 달라진 점 3줄 이내**.

### B. 전제 장부 — 이 규격의 중심
"어제 시장을 지탱/압박한 전제가 오늘도 유효한가"를 표로 관리한다.

| 전제 | 어제 상태 | 오늘 새 정보 | 상태(강화/약화/뒤집힘/무변화) | 근거 | 이 전제가 깨지는 조건 |
|---|---|---|---|---|---|
| 예: 고유가는 호르무즈 공급 차질 때문 | 지속 | … | … | … | 통항 회복이 실제 물량으로 확인 |
| 예: AI 투자가 높은 금리를 버티게 함 | 유지 | … | … | … | 주요 기업 투자·주문 하향 |

- 전제는 3~5개로 제한한다. 늘리면 중구난방이 된다.
- 전제마다 **반전 조건을 미리 쓴다.** 조건이 충족되면 판단을 바꾼 사유를 다음 날 헤더에 남긴다.

### C. 오늘의 사건 축 (2~3개)
지금 가격을 움직이는 사건만 고른다. 교과서식 원인 나열 금지.
각 사건마다 고정 항목:
1. 현재 상태 (원문 링크, `[확인]`)
2. 유지될 때의 경로 `[추정]`
3. 반대로 가려면 필요한 일 (예: 합의 이행·선박 통항 수치)
4. 뉴스 기대 vs 실제 이행 구분 ("협상한다" ≠ "물량이 나온다")
5. 오늘 확인할 지표

### D. 전달 경로 체인 (자동 표)
사건이 가격까지 실제로 전달됐는지 고리마다 확인한다.

`유가 → 기대인플레·물가 → 2년물(정책 기대) → 10년물 → 나스닥/반도체 → 달러 → 원/달러 → 외국인 → KOSPI`

| 고리 | 오늘 값 | 변화 | 가설과 방향 일치? | 기준일 |
|---|---|---|---|---|

- 방향이 안 맞는 고리가 있으면 그 고리가 "이 설명이 틀렸을 수 있는 자리"다. 굵게 표시하고 다른 요인을 후보로 적는다(예: 유가는 내렸는데 장기금리는 상승 → 국채 수급 등 `[추정]`).
- 같은 물가 충격을 여러 지표로 본 것은 **독립 신호로 합산하지 않는다** (유가·CPI·기대인플레는 한 묶음).

### E. 시장이 뉴스를 믿는가 (가격 확인)
- 나스닥 vs 반도체(SOX) 상대 강도, VIX, 달러.
- 악재 뉴스 후 하락 → 회복 여부, 좋은 뉴스에도 상승 제한인지.
- "지수가 버틴다 = AI가 받친다"는 **[추정]** 이다. 기업 이익 전망·투자 계획 자료가 붙기 전까지 확정하지 않는다.

### F. 금융 스트레스 사다리 (위험 3→4단계 대체)
유튜버의 "3단계/4단계"는 `[의견:인물]` 이다. 이를 그대로 채택하지 않고, **관측 가능한 지표의 점등 개수**로 바꾼다.

| 층 | 지표 후보 | 현재 수집 여부 |
|---|---|---|
| 신용 | 회사채 스프레드 | 한국 AA-−국고3년 있음 / 미국 하이일드 스프레드 **없음** |
| 변동성 | VIX | 있음 |
| 단기자금 | SOFR 등 레포 계열 | **없음** |
| 국채 유동성·변동성 | 국채 변동성 지수 등 | **없음** |
| 달러·원 | DXY, 원/달러 | 있음 |

- 초기에는 임계값을 만들지 않는다. **방향 + 최근 변화 + 과거 대비 위치**만 표시하고, 임계값은 과거 분포를 본 뒤 달님이 정한다.
- 없는 항목은 숨기지 말고 "미수집"으로 표시한다. 확인 못 한 걸 "정상"으로 쓰지 않는다.

### G. 이슈 지속성 장부
한 번 나온 말은 단기 조정, 반복·확산·구체화되면 추세 재료라는 관점(달님 정리)을 표로 만든다.

| 이슈 | 첫 등장일 | 반복 횟수 | 발언 주체 수 | 단계(발언→일정→예산/주문) | 악재마다 반응이 커지나/줄어드나 |
|---|---|---|---|---|---|

- 단계가 올라가면(발언 → 실제 일정·예산 변경) 전제 장부의 해당 전제를 갱신한다.

### H. 한국 연결 (판단 재료만)
- 원/달러 수준·속도, 외국인 수급(현재 수집 여부 미확인), 반도체 수출, KOSPI/KOSDAQ 반응.
- 출력은 "한국 시장에서 오늘 무엇을 더 확인해야 하나" 목록. 매수·매도 표현 금지.

### I. 일정
오늘·이번 주 발표(CPI, 고용, 연준 발언, 협상 일정 등). 시장 예상치(컨센서스)는 자동 수집원이 없으면 `[미확인]` 로 두고, **발표값이 아니라 예상 대비 차이**가 중요하다는 점만 상기시킨다.

### J. 이 보고서가 틀리는 경우
- 오늘의 결론과 **반대되는 시나리오 1개**, 그것이 맞다면 오늘 어떤 지표가 다르게 움직였어야 하는지.
- 어제 결론과 달라졌다면 사유.

### K. 달님에게 넘기는 질문
결론 대신 판단이 필요한 질문 2~3개 (예: "전제 2가 약화됐다. 한국 반도체 관련 비중 점검 기준을 바꿀지?").

### L. 부록: 출처·미확인
- 사용한 모든 링크·파일 ID·기준시각, `[미확인]` 목록.

## 3. GPT 대화에서 가져온 것 / 버린 것

가져온다
- 금리 → 원인 구분 → 실제 가격 반응 → 자금시장 → 환율 순서의 분석 흐름 (B, D, F).
- "현재 사건 → 유지 시 경로 → 반전 조건 → 실제 반응 확인" (C).
- 예상 대비 차이가 중요하다는 점, 수치 하나가 아니라 방향·속도·지속기간을 본다는 점.
- 반복·확산·구체화 (G), 전제를 매일 갱신 (B).

버린다 / 격리한다
- 위험 3단계·4단계, 5.25%, -3%, 15%, "1,380원" 같은 **유튜버의 기준값** → `[의견:인물]` 로 격리, 임계값으로 사용하지 않음.
- GPT가 인용한 뉴스·연준 연설·기사 날짜(9/14, 9/25, 9/26, 9/28 등) → 이번 작업에서 **원문을 열어 확인하지 않았다.** 링크 검증 전에는 `[미확인]`.
- "AI가 시장을 받치고 있다"는 인과 → `[추정]`.
- 어조가 논지에 끌려가는 부분(예: 하락 위험 강조 → 해당 근거만 수집) → 반대 시나리오(J)를 필수 칸으로 강제.

## 5. 단계 (코드는 3단계부터)

1. **1~2주: 문서로만.** 이 틀로 보고서 10회 이상 받는다. 숫자 표는 `facts/macro.json` 값을 복사해 붙인다. 프로그램 변경 없음.
2. **평가.** 아래 기준으로 유용성 판정.
   - 읽는 데 5분 이내인가
   - 전제 장부 갱신 사유가 매번 원문으로 추적되는가
   - `[미확인]`·틀린 숫자가 몇 건 나왔는가
   - 보고서가 놓친 큰 사건이 몇 건인가 (사후 비교)
3. **유용하면:** 숫자 표(D, F)만 자동 채움, 보고서를 보관실 기록으로 저장. 보관실은 폐지하지 않고 "원문·근거·복기" 역할에 맞춰 응용.

## 6. 현재 데이터의 알려진 문제 (보고서 신뢰도에 직접 영향)

- `[확인]` 미 10Y/2Y는 2026-09-28 기준이라 09-30 아침 수집분에서도 1~2일 늦다. 신선도 표시가 필수.
- `[확인]` 미국 지수·유가 항목의 `as_of` 가 09-30 이지만 수집은 09-30 08:33 KST 다. 미국 장 마감 기준일인지 한국 날짜인지 **표기가 모호하다**(`[추정]` 미국 09-29 종가일 가능성). 보고서에는 "미국 마감 기준 여부 미확인"을 붙이거나 `as_of` 정의를 먼저 고친다.
- `[확인]` 연준 실효금리 3.63%(2026-08) vs 2년물 4.92%(09-28). 두 값의 간격이 크다. 값 오류인지 실제 시장 가격의 인상 기대인지 **미확인** — 보고서에 쓰기 전 원자료로 대조.
- 브렌트유는 수집하지 않는다(WTI만 있음). 영상의 "브렌트 100달러"는 현재 수집값으로 검증 불가.

## 7. v0.2 추가 — 톱니바퀴 수명주기 (2026-09-30, 달님 요청 반영)

목적 재정의: 보고서는 지표 나열이 아니라 **이슈가 생기고·유지되고·반대급부에 소멸하는 흐름**을 읽어, 진입/이탈 판단의 재료를 주는 것이다. 위 §2의 B(전제 장부)·G(이슈 지속성 장부)를 아래 이슈 장부로 통합한다.

- 이슈 = 원인 → 전달 → 가격 반영이 이어지는 톱니 1개. 이슈마다 ID(G1…), 유형(완만/급변) 부여.
- 수명주기: ①점화 ②확산 ③가격반영 ④포화 ⑤반대급부 출현 ⑥소멸/전환 ⑦재점화.
- 소멸 점검 3문항: A 원인 지표 반전 / B 반대급부 **실이행**(발언·제안은 불인정) / C 가격 둔감화. 근거 없으면 "미확인"이며 예로 세지 않는다.
- 이음매 점검: 톱니끼리 방향이 맞는지 매일 확인하고, 안 맞는 곳을 "어긋남"으로 기록한다 (예: 유가 하락인데 장기금리 상승).
- 투자 연결: 보고서는 달님이 미리 적은 규칙의 충족 여부만 표시한다. 규칙 자체와 매수·매도는 달님이 정한다.
- 전일 장부를 다음 날 보고서 상단에 복사해 이어간다. 첫 기준본: `docs/reports/2026-09-30.md`.
- 한계: 소멸 3문항은 과거 사례로 검증되지 않은 초기 가설이다. 4주 운영 후 놓친 전환점·거짓 소멸 건수로 평가한다.
