- 확인: 기존 지표 정의와 수집 데이터의 항목 수가 달랐다. 누락을 0으로 대체하지 않고 표시했다. 수집기가 갱신하면 추가 값도 자동 반영한다.
- 변경: 별도 chatgpt 경로, 데이터/차트/기록 모듈 분리, 고정 지표 ID, 뉴스 주소 정규화, 서울 시간 및 미국 서머타임 표시.
- 시도 1: Git 다운로드 도구의 HTTPS 지원 부재로 실패. 공식 저장소 아카이브로 원본을 확보했다. 원격 반영은 GitHub 연결 도구로 수행.
- 시도 2: 초기 상세 이동은 브라우저 전체 이력을 사용해 외부 사이트로 돌아갈 수 있었다. 앱 내부 경로 이력으로 변경.
- 시도 3: 초안 복원과 사용자의 새 입력이 경합할 수 있었다. 입력 시작 여부와 페이지 세대 번호로 오래된 복원을 차단.
- 시도 4: 관련 뉴스 최신순에서 일반 키워드가 포함된 주변 기사가 앞섰다. 제목·등록 키워드·본문의 일치 가중치 순으로 개선. 인과관계 확정은 하지 않는다.
- 시도 5: 저장소의 기존 권한 구조를 확인해 개인 기록의 안전한 분리가 필요했다. 새 기록 연결은 본인 인증·서버 규칙 검증 완료 전 차단했다.
- 검증: 숫자 결측, %p, 0 기준 변화율, 판정/방향 분리, 정의 병합, 이력 기간, KST/DST, 뉴스 중복/검색, 주소/HTML 처리 8개 자동 검사 통과. 브라우저에서 지표→상세, 뉴스 본문 검색, 저장 실패 시 입력 보존·재진입 복원 확인. 390px 화면의 문서와 상세에 가로 넘침 없음, 기본 글자 16px 확인.
- 미검증: Google 본인 로그인 후 실제 온라인 저장·다른 기기 동기화. 실제 iPhone/Android 기기별 검증. 발표 이력 전체 및 원출처 수치 대조.
- 한계: 차트는 원 수집기의 일별 스냅샷이다. 적은 표본으로 상관계수·시장 순환·미래 방향을 만들어내지 않는다. 뉴스 원문 자체의 사실 검증을 완료한 것은 아니다.
- 복구: 이 앱 경로의 이전 GitHub 커밋으로 코드 복원. 개인 기록은 코드와 분리하므로 코드 복원 때 삭제하지 않는다. 권한 복원 시 신규 개인 기록을 다시 공개하는 규칙으로 되돌리지 않는다.
- 교훈: 공용 저장소 설정을 복제하기 전에 실제 권한을 확인한다. 비동기 화면 변경에는 오래된 결과 차단을 둔다. 수집일과 관측일, 상승과 우호 판정을 혼동하지 않는다.
