# 매크로 관측실 작업 규칙
- docs/ARCHITECTURE.md와 docs/CHANGELOG.md를 읽고 시작한다. 최신 사용자 직접 지시 우선.
- 사용자 한 명, 한국어, 파스텔 라이트, 본문 16px 이상, 모바일, 전체 조망과 상세 이동 유지.
- 기존 invest 프로그램 파일은 별도 요청 없이 변경하지 않는다.
- 각 배포는 release.json에 누적 버전·실제 서울 시각·요약을 갱신하고 build.mjs를 실행한다. 변경 실패와 검사 결과를 CHANGELOG에 누적한다.
- 개인 기록·인증 토큰·계정 이메일·비밀키를 공개 저장소에 넣지 않는다. 공개 Firebase 웹 설정은 접근 권한을 대신하지 않는다.
- core 자동검사와 변경 관련 화면 검사를 수행한다. 미검증을 완료라고 쓰지 않는다.
- 신규 기능 실패로 기존 지표 화면이나 개인 기록을 잃지 않게 한다. 사용자 데이터는 추정하거나 자동 덮어쓰기하지 않는다.
